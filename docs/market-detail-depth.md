# Model and subscription detail depth

The public guide now puts useful facts before catalog mechanics. Models combine published token prices, sourced context/output limits, modalities, capabilities and places to use them. The library filters capabilities and compares selected models' specifications alongside prices. Model limits describe API specifications, not subscription quotas.

Subscriptions lead with price, included usage and supported tools. Usage windows, credit behavior, purchase restrictions and other commercial terms are inspectable on the plan page. Technical family identity records no longer compete with named releases. Opaque capacity stays opaque even when the price and access facts are verified.

## Source completion

- All 49 listed releases now have sourced developer identities.
- 37 releases have first-party specifications. Unpublished or unresolved fields are omitted, not guessed from adjacent models.
- Eleven previously missing models receive current direct API reference prices: GPT-5.4 nano, Claude Opus 4.7 and Sonnet 4.6, Gemini 3.5/3.6/3.7 Flash, Grok 4.5/4.6, Kimi K2.7 Code/K3 and Muse Spark 1.3.
- Claude cache-write durations remain separate. Gemini promotions have an explicit end date. Meta's contributor rate is not substituted for its standard model.
- Composer's Cursor product prices and Nano Banana Pro's modality-specific prices are explained without creating a misleading generic direct API rate.
- ChatGPT-only labels, retired Gemini 3 Pro Preview and unresolved exact API identities have specific explanations. Sonnet 5 is labeled legacy according to its current model page.
- Fourteen subscription descriptions now summarize their existing sourced usage terms. Both ChatGPT Pro tiers list Codex. Cursor Hobby's documented price and terms are verified; its numeric capacity remains unknown.

Reference prices do not automatically admit new execution routes. There are no new optimizer semantics or subscription-capacity estimates. Family-level subscription access is explicitly distinguished from exact-release availability.

## Design reference

Artificial Analysis informed the visual comparison of separate price categories; models.dev informed capability and context discovery; OpenRouter informed the relationship between models, prices and access. Provider documentation remains the authority for commercial and technical facts. No external benchmark scores or quality rankings were imported.

The presentation uses the existing typography, fine rules and Signal Blue, with spacious detail pages and concise library rows. Sources and identity mechanics remain secondary. No personal histories or billing facts are used.

The price chart now pairs Fable/Astra, Opus/Sol, Sonnet/Terra and Haiku/Luna, followed by GLM 5.3 and DeepSeek V4.1 Flash. Pairs are ordered by their higher selected-category price; alternatives and user-selected comparisons sort from highest to lowest price. Every bar uses the same labeled linear scale. These are editorial browsing pairs, not model-equivalence or popularity claims. Explore models uses a separate coding shortlist by default. Google and Composer remain available through search, filters and the full library without leading either default view.
