# Import to Workload

A successful import saves normalized usage through the existing worker, shows recorded calls, known tokens, projects, span and sources for 800 ms, then opens that exact workload automatically. Import no longer runs pricing or waits for profile analysis. Workload owns both calculations and the useful result.

The handoff uses client navigation, so an intentionally temporary workload remains usable without IndexedDB persistence. Canceling, replacing or clearing a scan, or leaving the page, invalidates its pending handoff. Failed imports stay on Import with their existing error and recovery path.

A later, intentional Import visit manages sources and saved snapshots. Each snapshot has a closed **Import details** disclosure for source outcomes, token categories and parser notes. Export, Replay and deletion remain available there. A previously selected plan is carried through to a secondary Replay link in Workload evidence.

Routine ignored files do not compete with the completion facts. Material unreadable or incomplete source files still produce the existing partial-scan notice beside Workload totals. An unsaved workload remains explicitly labeled on Workload.

The scan's stage rail is unchanged while running. On mobile its completed state compresses to leave room for the final readings. Browser coverage exercises the timed handoff, dark/light and mobile layouts, persistence, temporary imports, re-imports, cancellation, navigation away, harmless ignored files and material scan failures. Raw history and billing facts remain local.
