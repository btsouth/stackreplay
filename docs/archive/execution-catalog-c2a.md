## Difference from the prior research branch

`3e7bb1d` was discovery, not admitted truth. Its `docs/execution-market/market-census.md` flagged an OpenCode Go disagreement; the current two official pages now state per-model dollar limits and turn the previously confusing $12/$30/$60 figures into one example. The current product set and prices were rechecked rather than copied from that branch. The pilot adds three exact direct API routes and two honestly non-computable subscriptions, not its wider P0 list. No provider-specific replay behavior, watcher, UI or automatic admission was added.

Wider P0 admission still needs claim-by-claim purchase/cohort checks, exact route and token-category evidence, reset anchors and continuation rules where those affect capacity, plus fresh review when this snapshot expires. Products requiring trailing windows or purchased-wallet allocation need their own later runtime milestone.
