# Interruption session context

Interruption rows show a readable date and time (UTC), project references, and affected sessions. Expanding an episode shows each blocked attempt with its own session, plus the preceding response and recorded session activity within the selected period.

Attribution requires the same local account and exact native session identity. Nearby activity in another session or account does not establish project attribution. A preceding response's model is context, not proof of the blocked request's model. Missing session history stays explicitly unavailable.

Native browser imports use locally saved project labels. Portable exports retain project hashes but omit private names; the timeline shows stable project references in that case. This context remains local and is excluded from aggregate sharing.

Grouping, reset interpretation, pricing, and existing impact annotations are unchanged. Session indexing happens in the cached worker analysis, not on disclosure expansion.
