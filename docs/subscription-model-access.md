# Subscription model access

Public subscription pages now show provider-published model lineups separately from the smaller set of exact routes admitted for Replay. Previously, Command Code Max displayed only its two recorded replay model identities. That was not its product lineup.

The September 28, 2026 review covers every currently listed subscription. Model names without canonical Replay identities remain visible and searchable. They do not acquire API prices, routing aliases or capacity rules merely by appearing here.

- Command Code: separate Go, GOAT, Pro and Max source tables, including 86 named Max models. The lower tiers do not inherit Max's premium lineup.
- ClinePass: all 12 published choices. OpenCode Go/Go Plus: 30 named choices and temporary free-model conditions. Ollama: 17 current cloud choices, separate from local models.
- Claude: current supported models including Sonnet 5.5; Fable remains usage-credit-only on Pro and part of Max's model-specific allowance.
- ChatGPT: Chat and Work/Codex groups; Pro-mode access is not attributed to Plus.
- Copilot: per-plan model matrix, including Sonnet 5.5. Monthly plans exclude retired Sonnet 4.6; GPT-5.4 nano retains its Pro+ Codex-extension restriction. Free uses Auto selection.
- Cursor: separate Cursor and Other Models pools, including Sonnet 5.5. Hobby does not inherit the paid lineup.
- Kiro: named models and experimental regional rollouts are separate; Enterprise-only Fable is not a Pro entitlement.
- Google AI: Gemini Apps, Antigravity and image generation are separate, including Antigravity's Claude and GPT-OSS choices.

Every group links its official source and records the review date. Subscription detail shows a compact searchable lineup; plan search and comparison consume the same public access record. Canonical links use explicit identities only. Current observations are not applied to earlier dates.

Source-of-truth boundaries: `subscription-access-data.json` is reviewed public product information, not an execution catalog. Replay model rules, pricing, allocation and opaque-capacity semantics are unchanged. Provider rollouts, geography, workspace controls and model retirement can change availability after this snapshot.
