# Suggested replays

Replay now chooses one counterfactual strategy. Compare reads completed local results side by side. Billing-period comparisons and manual target selection remain explicit secondary paths.

## Workload first

The initial page reads the normalized model/source mix, accepted routes, and current stack. It offers exact direct APIs when some calls are priceable, applicable explicit frontier profiles, and a current-stack assessment when selections exist. Build your own retains the manual tools and full target browser. No economy policy is suggested without an approved mapping.

Exact APIs reuse the cached full-import Workload market result, including both Claude cache-write scenarios. No dates or sources are dropped. An incomplete result reports priced-scope economics without a whole-workload difference.

## Explicit translation

Version 1 of the OpenAI frontier profile enumerates canonical Opus releases to GPT-6 Sol, Sonnet releases to GPT-5.6 Terra, Haiku releases to GPT-6 Luna, and Fable releases to GPT-6 Astra. The reverse profile only supplies the explicit Astra to Fable 5.1 pair. These are counterfactual policies, not accepted model equivalence or alias claims. Every suggested mapping can be inspected, edited or cleared before Run.

The existing token-preserving provider API evaluator supplies translated costs, including its accepted category prices, context tiers and reasoning treatment. Its rules date is the market snapshot's calendar date; the exact baseline retains its full admitted-route timestamp. Recorded input, cache, output and reasoning quantities are preserved. Actual output quality, tokenization and cache behavior could differ. Reverse Claude suggestions are withheld when cache-write usage needs the two-duration scenario machinery that this evaluator does not support.

No catalog data, optimizer semantics, quota rules or routing capabilities changed. Opaque subscriptions retain known published prices and access but have no fabricated combined capacity or cost comparison.

## Results and Compare

Results lead with API cost, replay-minus-baseline difference, retained and priced calls, and translated model count. Mapping rows show workload contributions; target model totals come from the existing receipts. Partial pricing never becomes a whole-workload difference. Exact replay's difference is zero because its baseline is the same correlated calculation.

Add to Compare stores up to 20 validated aggregate results locally. Comparisons require the same import, scope digest, call count, catalog hash and pricing snapshot. Compare does not invoke pricing. Reload preserves results; deleting an import or clearing local data removes them. Public sharing is unchanged. No raw history, session IDs, personal billing facts or project names are stored in these comparison records.

## Validation

The existing privacy-safe local import contained 43,793 responses, 15.42B known tokens and five Claude models. Its exact result remained $8,449.13–$9,283.22. The explicit frontier policy priced all 43,793 calls at $14,963.52, a factual difference of $5,680.30–$6,514.40. This is not an equal-quality or subscription-replacement claim.

In the isolated desktop browser, cached exact composition took about 35ms and translated execution about 823ms. Compare added no pricing run and survived reload. The browser blocked outbound writes; no raw data or billing state was committed or uploaded. Dark, light and mobile review covered suggestions, confirmation, exact/translated results and Compare.
